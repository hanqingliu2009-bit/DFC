# DFC · 拉力曲线绘制工具

交互式拉力–拉距曲线绘制、多曲线对比与蓄能计算（桌面 / 浏览器）。

仓库：https://github.com/hanqingliu2009-bit/DFC

版本更新见 [CHANGELOG.md](./CHANGELOG.md)。当前版本 **1.1.1**。

## 功能概览

### 交互模式
- **浏览**：拖拽平移视图，滚轮缩放；不会误改测点
- **编辑测点**：单击添加、拖拽调整、双击测点删除；Alt / 中键仍可平移

### 多曲线与导入导出
- **导入 CSV**（可多选）：按**文件名**命名曲线，叠加到同一张图
- **双击曲线**（或点图例 / 曲线列表）切换当前可编辑曲线；加粗高亮为当前曲线
- **导出 CSV**：导出当前曲线测点
- **导出图片**：离屏专用排版（非界面截图）
  - 单曲线：左图右测量
  - 多曲线：竖向长图，含对比摘要表 + 每条完整测量数据
  - 图表缩放与浏览区一致，避免横向拉扁

### 曲线显示与积分
- **折线**：测点直线相连，梯形积分
- **平滑样条**：Akima 局部三次样条（改一点主要牵动附近几段）；灰虚线为折线对照
- 平滑模式下加密采样，显示与蓄能计算共用同一套采样点
- 曲线颜色高对比（橙 / 蓝 / 玫红 / 近黑 / 金 / 紫 / 绿 / 赭）

### 蓄能与指标
- **储存能量 (J)**：曲线下面积 \(E = \int F\,dx\)
- **每磅蓄能 / 每千克蓄能**：总蓄能 ÷ 峰值拉力
- **蓄能系数**：曲线下面积 ÷（½ × 拉距跨度 × 当前拉力）
- 鼠标沿当前曲线滑动时，动态显示位置、当前蓄能、蓄能系数及参考三角形

### 单位制
- 右上角切换 **公制 / 英制**
  - 公制：拉距 **cm**，拉力 **kg**，每千克蓄能 **J/kg**
  - 英制：拉距 **in**，拉力 **Lb**，每磅蓄能 **J/Lb**
- 内部统一按 **cm + Lb** 存储与计算
- 换算：`1 Lb·cm ≈ 0.04448 J`；`1 in = 2.54 cm`；`1 Lb ≈ 0.4536 kgf`

### 视图
- 滚轮以指针为中心缩放；工具栏放大 / 缩小 / 适应数据 / 复位
- 可手动改坐标轴范围；横轴贴数据、纵轴略收，便于观察拉力起伏

## CSV 导入说明

两列：拉距、拉力。建议带表头并标明单位。

| 表头示例 | 处理 |
|---------|------|
| `拉距厘米,拉力磅` / `draw_cm,force_lb` | cm + Lb |
| `拉距英寸,拉力磅` / `draw_in,force_lb` | in→cm，Lb |
| `拉距厘米,拉力千克` | cm，kg→Lb |
| `拉距,拉力`（无单位） | 默认 **cm + Lb** |
| 无表头纯数字 | 默认 **cm + Lb** |

也识别：行程、力值、公分、吋、公斤，以及 `cm` / `in` / `lb` / `kg` 等。  
冲突单位时：厘米优先于英寸，磅优先于千克。

导出 CSV 按当前单位制写表头（公制 `拉距_cm,拉力_kg`，英制 `拉距_in,拉力_lb`）。

## 开发调试

```bash
npm install
npm run dev            # 浏览器：http://localhost:5173
npm run dev:electron   # Electron 桌面窗口
```

## 打包绿色版（给客户）

新功能已打进前端 `dist`，打包配置无需额外改动，重新打包即可：

```bash
npm run pack
# 自定义 zip 文件名（可省略 .zip）
npm run pack -- 拉力曲线-客户A
# 或只打 zip（需已有 win-unpacked）
npm run zip -- 拉力曲线-客户A
# 环境变量亦可：set ZIP_NAME=拉力曲线-客户A&& npm run pack
```

产物目录：`D:\dev\DFC-release\`

| 路径 | 说明 |
|------|------|
| `DFC拉力曲线-<version>-绿色版.zip` | 默认 zip 名（可用参数覆盖） |
| `win-unpacked\` | 解压后的完整程序（打包中间产物） |

**客户用法：** 解压 zip → 打开 `DFC拉力曲线` 文件夹 → 双击 `DFC拉力曲线.exe`。

> 单文件 portable exe（`npm run pack:portable`）可用，但自解压外壳图标容易异常，推荐仍用 zip 绿色版。

## 技术栈

- React + TypeScript + Vite
- Electron（桌面绿色版）
- `html-to-image`（导出 PNG）
- 蓄能：梯形积分；平滑模式基于 Akima 局部样条加密采样
