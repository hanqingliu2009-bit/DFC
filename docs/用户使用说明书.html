3. 公制 / 英制

右上角可随时切换，已输入的拉距、拉力会按规则换算。

公制 英制
拉距 cm in
拉力 kg Lb
每单位蓄能 / 动能 J/kg J/Lb
建议：测速与记录若习惯用英寸和磅，全程使用英制；国内拉力计若显示千克，用公制更直观。

4. 拉力曲线：绘制、导入与蓄能

4.1 两种使用方式

方式 A：导入 CSV → 叠加到图上 → 对比 / 导出图片
方式 B：新建空白曲线 → 命名 + 手动画点 → 导出 CSV 存档

4.2 浏览与编辑

  • 浏览：拖拽平移视图，滚轮缩放；不会误改测点。
  • 编辑测点：在图上单击添加、拖拽调整、双击测点删除；按住 Alt 或中键仍可平移。
  • 折线 / 平滑样条：折线为直线相连；平滑为 Akima 样条（改一点主要影响附近）。蓄能按当前曲线模式计算。

4.3 给曲线命名（重要）

在右侧「测点」区域顶部的曲线名称中填写，例如 我的弓。列表与图例会同步；之后「导出 CSV」时，文件名就是这个名称。

4.4 多曲线对比

  • 「导入 CSV」可多选，按文件名命名并叠加。
  • 双击某条曲线，或点图例 / 曲线列表，切换「当前」可编辑曲线（加粗高亮）。
  • 「新建曲线」可再画一条空白曲线。

4.5 蓄能读数

至少 2 个测点后，侧栏会显示：

  • 储存能量 (J)：曲线下面积
  • 每磅 / 每千克蓄能
  • 蓄能系数等

鼠标沿当前曲线滑动时，可看当前位置的拉力、蓄能与参考三角形。

5. CSV 格式说明

两列：拉距、拉力。建议带表头并标明单位。

表头示例 软件如何理解
draw_in,force_lb 或 拉距英寸,拉力磅 英寸 + 磅
draw_cm,force_lb 或 拉距厘米,拉力磅 厘米 + 磅
拉距厘米,拉力千克 厘米 + 千克（内部换算为磅）
无单位 / 无表头纯数字 默认按 cm + Lb
导出：按当前单位制写表头；文件名 = 当前曲线名称（例如 我的弓.csv），不再附加 imperial / metric 后缀。

6. 箭动能与 Virtual mass

6.1 计算箭动能

  1. 切换到顶部标签 箭动能。
  2. 输入箭重（grain 或 g）与箭速（FPS 或 m/s）。
  3. 立即得到动能 J。可「添加一支箭」做多组对比。

6.2 可选：测速拉距 / 拉力 / 效率

  • 填写测速拉距。
  • 拉力曲线可选「无」：此时可手动输入测速拉力，用于算 J/Lb 或 J/kg。
  • 若关联某条拉力曲线：自动读取该拉距下的拉力与蓄能，并计算效率（箭动能 ÷ 测速拉距下蓄能）。未关联时蓄能与效率留空。

6.3 Virtual mass（虚拟质量）

当你录入两支不同重量箭的质量与箭速后，页面上方会显示 Virtual mass：

  • 主单位：g
  • 括号内：格令
含义（通俗）：把弓臂、弦等「跟着箭一起被加速」的部分，折算成一个等效质量。数值越小，通常表示弓更「轻快」。计算假定两次测速拉距与可用蓄能相同，请尽量在相同拉距下测两支箭。

切换回「拉力曲线」标签时，箭动能页已填数据会保留。

7. 导出图片与报告

  • 拉力曲线 → 导出图片：生成专用排版的 PNG（不是简单截屏）。多曲线时为竖向长图，含对比摘要与各曲线数据。
  • 箭动能 → 导出图片：竖屏汇总表 + 分项结果。

图片一般保存在浏览器 / 系统默认下载目录（桌面版同样走下载逻辑）。

8. 常见问题

解压后双击没反应？

确认是从解压后的完整文件夹启动；可尝试右键「以管理员身份运行」，或检查杀毒软件是否拦截。

导入 CSV 后曲线很怪？

检查单位是否与表头一致（英寸误当厘米最常见）。可先切换到对应单位制再导入，或改正表头后重试。

为什么没有 Virtual mass？

需要至少两支箭都填好有效质量与箭速，且两支箭重量要不同；箭速过于接近时也可能算不出。

效率为什么是空白？

效率依赖「关联拉力曲线 + 有效测速拉距」。拉力曲线选「无」时只手填拉力，不算蓄能与效率。

数据会上传吗？

绿色版为本地运行，曲线与箭数据默认保存在当前会话中，不会自动上传到网络。
